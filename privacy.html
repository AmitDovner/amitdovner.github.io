Privacy policy

Hermes is a personal assistant used by a single person (its owner) on a server they control. It is not offered to the public.

What data is accessed

With the owner's explicit consent via Google OAuth, Hermes may read the owner's Gmail messages (read-only) and read and manage the owner's Google Calendar events.

How data is used

Data is used only to answer the owner's requests and to prepare reminders and summaries for the owner. It is not sold, shared with third parties for advertising, or used to build profiles of anyone else. Content may be processed by the AI model provider chosen by the owner solely to generate responses.

Storage and security

OAuth tokens are stored only on the owner's private server with restricted file permissions. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
